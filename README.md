# ICRA Interactive Sessions — Topic Map

一个更好用的 ICRA Interactive Session 论文浏览 & 筛选工具。

## 痛点

- ICRA 的 **Tue / Wed / Thu** 三天，每个 interactive session 都有 **500+ 篇 paper**，量大到很难快速找到自己关心的内容。
- 官方提供的 index page 虽然内容完整，但**不方便做自定义筛选**，按主题、关键词去捞论文的体验并不好。

## 这个项目做了什么

- 目前已经整合了 **Tuesday** interactive session 的全部内容（论文 ID 与官方 program 一一对应）。
- 提供了**更好用的 UI**：按主题分类折叠浏览，实时搜索，关键词高亮。
- 支持**自定义筛选**，让你更快定位到感兴趣的论文。

> 📌 后续会继续补充 **Wednesday / Thursday** 的内容。

## 使用方式

直接在浏览器里打开 `index.html` 即可，无需任何依赖或构建步骤。
