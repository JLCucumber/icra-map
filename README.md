# 🗺️ ICRA Interactive Sessions — Topic Map

> A friendlier way to browse & filter the ICRA Interactive Session papers.

## 🤔 The Problem

- Each of the **Tue / Wed / Thu** interactive sessions at ICRA packs in **500+ papers** — way too many to skim through and find what you actually care about.
- The official index page has *everything*, but it's **not built for custom filtering**. Hunting for papers by topic or keyword just isn't a great experience.

## ✨ What This Does

- 📚 Already integrates the **full Tuesday** interactive session (paper IDs map 1:1 to the official program).
- 🎨 A **nicer UI** — browse by topic with collapsible categories, live search, and keyword highlighting.
- 🔍 **Custom filtering** so you can zero in on the papers you care about, fast.

> 🚧 **Wednesday / Thursday** sessions are coming next.

## 🚀 Usage

Just open `index.html` in your browser — no dependencies, no build step.
